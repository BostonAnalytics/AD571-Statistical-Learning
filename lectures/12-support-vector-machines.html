19  Support Vector Machines

Author

Nakul R. Padalkar

Modified

June 12, 2026

Support vector machines use margins and kernels to construct classifiers that can be linear in a transformed feature space while nonlinear in the original variables.

19.1 Learning Objectives

  • Explain maximal-margin and soft-margin classification.
  • Interpret support vectors and the cost parameter.
  • Compare linear, polynomial, and radial kernels.
  • Explain why scaling is essential for SVMs.
  • Tune cost and kernel parameters with cross-validation.

19.2 Separating Hyperplanes

For classes coded as y_i \in \{-1,1\}, a separating hyperplane has the form

f(x) = \beta_0 + x^\top\beta.

The predicted class is the sign of f(x). If the classes are perfectly separable, many hyperplanes may classify the training data correctly. The maximal-margin classifier chooses the hyperplane with the largest distance to the closest training points.

Those closest points are the support vectors. They determine the boundary; observations far from the boundary do not directly control the fit.

19.3 Soft Margins

Perfect separation is rare and can lead to overly sensitive boundaries. The soft-margin classifier allows violations:

y_i(\beta_0 + x_i^\top\beta) \geq 1 - \xi_i, \qquad \xi_i \geq 0.

The cost parameter controls the penalty for violations. A large cost allows fewer violations and may produce a narrower margin. A small cost allows more violations and may produce a wider, more stable margin.

library(e1071)

linear_svm <- svm(
  class ~ .,
  data = train,
  kernel = "linear",

  scale = TRUE

from sklearn.preprocessing import StandardScaler

linear_svm.fit(X_train, y_train)

19.4 Kernels

Kernels compute similarity after an implicit feature transformation. This allows nonlinear boundaries without explicitly creating all transformed variables.

Kernel Form Boundary behavior
Linear x_i^\top x_j Linear in original predictors
Polynomial (c + x_i^\top x_j)^d Global curved boundaries
Radial basis \exp(-\gamma\|x_i-x_j\|^2) Local flexible boundaries

The radial kernel is often effective because it can create local nonlinear boundaries. Its flexibility depends on \gamma: larger values create more local influence.

19.5 Iris Decision Surfaces

A two-feature iris classification example makes kernels visible. Fit linear, polynomial, and radial SVMs on the same scaled predictors, then plot the predicted class across a grid. The linear kernel creates a straight boundary in the two-dimensional plot. The polynomial and radial kernels can bend around class structure.

  • R
  • Python
tuned <- tune(
  svm,
  class ~ .,
  data = train,
  kernel = "radial",
  ranges = list(cost = c(0.1, 1, 10), gamma = c(0.1, 1, 5))
)

best_svm <- tuned$best.model
from sklearn.model_selection import GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

svm_pipeline = make_pipeline(StandardScaler(), SVC(kernel="rbf"))
tuned = GridSearchCV(
    svm_pipeline,
    param_grid={
        "svc__C": [0.1, 1, 10],
        "svc__gamma": [0.1, 1, 5]
    },
    cv=5
)
tuned.fit(X_train, y_train)
best_svm = tuned.best_estimator_

This comparison should emphasize that better visual separation on the training data is not enough. Kernel choice and tuning parameters must be chosen with validation or cross-validation.

19.6 Scaling and Tuning

SVMs depend on distances and inner products, so feature scale matters. If one predictor has a much larger numeric range than another, it can dominate the margin and kernel values.

The usual tuning sequence is:

  1. split the data,
  2. center and scale predictors inside the training data,
  3. choose candidate kernels,
  4. tune cost and kernel-specific parameters by cross-validation,
  5. evaluate the selected model on held-out data,
  6. inspect support vectors and decision surfaces where possible.
